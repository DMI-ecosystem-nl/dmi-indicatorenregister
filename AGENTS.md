# Project rules

- `src/data/generated/register.ts` is generated by `scripts/extract-register.py`
  (`npm run extract`) from the files in `source-docs/` (gitignored). Never edit it
  by hand — change the script or the sources and re-run.
- Labels, colours, icons, order and the actielijn working titles live in
  `src/data/taxonomy.ts`; hand-written page copy lives in `src/data/content/`.
- Every view of indicators (cards, table, counts) filters through
  `filterIndicators()` in `src/lib/filters.ts`; shared lookups and counts go
  through `src/lib/selectors.ts` so pages never disagree.
- Filter state of the catalogue lives in the query string (`use-filter-params.ts`).
- Geschiktheid colours were checked with the dataviz palette validator; always
  pair them with a label/icon (`GeschiktheidBadge`), never colour alone.
- Motion: wrap with the global `MotionProvider` (`reducedMotion="user"`); do not
  branch `initial` on `useReducedMotion()` (causes hydration mismatches).
- Cache Components is on: dynamic routes use `generateStaticParams` and render
  their param-dependent content inside `<Suspense>`.
- Do not export personal names or informal session notes from the sources.
- UI language is Dutch; code identifiers are English.
